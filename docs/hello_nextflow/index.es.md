# Hello Nextflow

¡Hola! Estás en el camino para crear workflows científicos reproducibles y escalables utilizando Nextflow.

Con el advenimiento de los grandes volúmenes de datos (big data), se ha vuelto cada vez más necesario tener la capacidad de analizar y llevar a cabo experimentos con grandes conjuntos de datos de forma portátil y reproducible.
La paralelización y distribución del cómputo son las mejores formas de enfrentar este desafío, pero las herramientas comúnmente disponibles para los científicos computacionales suelen tener un pobre soporte para estas técnicas, o proveen un modelo que no se ajusta adecuadamente a las necesidades de estos científicos. Nextflow fue creado particularmente para abordar estos desafíos.

Durante este entrenamiento, serás introducido a Nextflow en una serie de workshops prácticos complementarios.

¡Vamos a empezar!

[![Open in Gitpod](https://img.shields.io/badge/Gitpod-%20Open%20in%20Gitpod-908a85?logo=gitpod)](https://gitpod.io/#https://github.com/nextflow-io/training)

## Objetivos de aprendizaje

En este workshop, vas a aprender los conceptos fundacionales para la construcción workflows.

Al final de este workshop vas a poder:

- Describir y utilizar componentes centrales de Nextflow suficientes para la construcción de un simple workflow multi-paso
- Describir conceptos como operadores y fábricas de canales
- Ejecutar un workflow localmente utilizando Nextflow
- Encontrar e interpretar salidas (resultados) y archivos de log generados por Nextflow
- Diagnosticar y solucionar problemas básicos

## Audiencia y pre-requisitos

Este es un workshop para aquellos que son completamente nuevos en Nextflow. Se asumen conocimientos básicos de la línea de comandos y formatos de archivo comunes.

**Pre-requisitos**

- Una cuenta de GitHub
- Experiencia con la línea de comandos
